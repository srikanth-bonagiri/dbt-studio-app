# DBT Studio

A modern, enterprise-grade web application for DBT code transformation and operations. Convert legacy ETL/SSIS to dbt models, optimize with MCP server capabilities, and manage your complete dbt workflow lifecycle.

## Features

- AI-Powered Conversion from SSIS/SQL to dbt
- MCP Optimization with best practices
- Auto-generate data quality tests
- Interactive lineage graphs
- Real GitHub CI/CD integration
- Monitoring & observability
- Demo mode for sales presentations
- Admin & governance

## Tech Stack

- React 18 + TypeScript
- React Router v7 (Data Mode)
- Tailwind CSS v4
- Radix UI components
- Recharts for analytics
- ReactFlow for lineage
- Motion (Framer Motion) for animations

## Getting Started

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev
```

The app will be available at `http://localhost:5173`
